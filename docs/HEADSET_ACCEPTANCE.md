# 头显与真实云盘验收清单

目标：Vision Pro、Quest、PICO 不安装 Localis App；Vision Pro 也不安装证书或描述文件，只在自带浏览器访问可信局域网 HTTPS 地址。超分只允许在电脑端运行。

每次记录：设备型号、OS/浏览器版本、电脑 CPU/GPU、FFmpeg 编码器、Wi-Fi 路由器、源文件编码/分辨率/帧率、超分档位、Localis 诊断 JSON、截图或录屏。

## 每台设备都要完成

- [ ] 全新浏览器会话打开可信 HTTPS 地址，没有证书警告。
- [ ] 输入电脑终端显示的六位码进入媒体库；未配对 API 返回 401。
- [ ] 全程没有安装 App、证书、描述文件或浏览器扩展。
- [ ] 头显页面看不到“添加媒体文件夹”与“连接云盘”，但能看到并播放媒体。
- [ ] MP4 Range 直放 20 分钟，暂停、恢复、向前/向后拖动各 10 次。
- [ ] AVI/MKV 兼容 HLS 播放 20 分钟，记录首帧时间和 buffering 次数。
- [ ] 中文外挂字幕在网页播放器和 WebXR 中都可读。
- [ ] VR180 SBS LR 左右眼正确、前方居中、背后为暗场。
- [ ] 360 Mono 接缝方向正确，抬头/低头没有颠倒。
- [ ] 手动切换 SBS/TB、LR/RL 和 yaw 后立即生效，退出/重进 XR 仍正确。
- [ ] WebXR 空间按钮可以播放/暂停、±10 秒、退出。
- [ ] 同一低分辨率片源依次选择“关闭 / 标准 / 高 / 极致”，Network 中分别出现 `/hls/off|standard|high|ultra/`。
- [ ] 标准/高/极致播放时，电脑 FFmpeg/GPU 有负载；头显页面没有 `.super-resolution-canvas`，视频元素仍为原生 controls。
- [ ] 开启超分连续观察至少 10 分钟，确认画面和字幕同时推进，不再出现“画面冻结、只有字幕移动”。
- [ ] 档位切换后播放位置与播放/暂停状态尽量保持，画面分辨率符合诊断中的输出尺寸。
- [ ] VR180 SBS 开启超分后左右眼边界没有颜色串入；TB 同样不跨眼混色。
- [ ] TB 左眼看到源画面的上半帧、右眼看到下半帧；切换 RL 后两眼精确互换，没有上下颠倒。
- [ ] 反复进入/退出 XR 10 次，视频继续使用同一条电脑 HLS，不创建设备端超分 render target。
- [ ] 待机再唤醒、退出再进入 XR、Wi-Fi 断开 10 秒再恢复后仍可继续。
- [ ] 连续播放 30 分钟，记录丢帧、音画漂移、发热和电脑转码速度。
- [ ] 4K/60 且仍在 H.264 Level 5.2 安全范围的源，在较低档位保持原分辨率并只锐化，不能被偷偷缩小。
- [ ] 选择一个源尺寸或像素率超过 H.264 Level 5.2 的样本；超分档应明确显示不可用并提示原片/HEVC，不能生成降采样伪“超分”流。

## Vision Pro 额外项

- [ ] Safari `navigator.xr.isSessionSupported('immersive-vr')` 为 true。
- [ ] 目视 + 捏合 transient-pointer 命中空间大按钮；未捏合时不依赖持续 `inputSources[0]`。
- [ ] 沉浸会话内有声音；最低按项目目标 visionOS/Safari 版本验收。
- [ ] 通过 Mac Safari Web Inspector 保存控制台与网络时间线。
- [ ] 标准档连续播放 30 分钟，对比关闭状态记录头显丢帧、发热、电量和电脑负载。
- [ ] 4K VR180 SBS 分别使用标准和高档进入/退出沉浸模式，记录诊断中的源/输出尺寸与首帧时间。
- [ ] 在曾复现“超分画面卡住、字幕仍动”的同一片源和同一路由器上回归，录制至少 10 分钟证据。

## Quest / PICO 额外项

- [ ] 左右控制器 trigger 均可选择按钮，不依赖固定 gamepad 索引。
- [ ] 手势/控制器切换和 `inputsourceschange` 后仍可操作。
- [ ] Chromium Local Network Access 或站点权限没有阻断同源 LAN HTTPS。

## 真实夸克/OpenList

- [ ] OpenList 仅监听 `127.0.0.1:5244`；另一台 LAN 设备直连 5244 应失败。
- [ ] `localis-reader` 只有 WebDAV Read 与目标夸克目录权限。
- [ ] Localis 成功列出真实夸克视频、音频和中文嵌套目录。
- [ ] 原文件模式在 10%/50%/90% 三处 seek；Network 只出现 Localis 8080 URL，不出现 OpenList 凭据或夸克 Cookie。
- [ ] 标准档显示“从云盘缓存到电脑”的百分比，缓存完成后电脑启动 FFmpeg，头显收到 HLS。
- [ ] 自有测试文件缓存后计算 SHA-256，与夸克原文件一致。
- [ ] 30 分钟播放、账号凭据过期、限速和 OpenList 重启后都有可读错误并能恢复。

## 真实百度官方 API

- [ ] 使用测试专用“软件”应用与测试账号，不把 SecretKey 提交到 Git。
- [ ] Localis 显示官方设备码二维码，百度网盘 App 扫码后成功连接。
- [ ] 只列出 `/我的应用数据/应用名` 中的媒体；其他目录不会意外出现。
- [ ] 10%/50%/90% seek 返回正确 Range；浏览器看不到 dlink 或 Access Token。
- [ ] 标准档先完成电脑缓存，再生成 HLS；缓存文件大小与测试源一致。
- [ ] Access Token 刷新后，新 Refresh Token 被保存且旧值不再使用；并发播放只发生一次刷新。
- [ ] dlink 过期后重新解析一次并恢复；普通/会员账号分别记录速度，不承诺绕过百度限速。
- [ ] 目录数量超过单页时继续使用百度 `start` 游标；含 64 位 `fs_id` 的文件可以精确获取 filemetas，超过 10,000 项时显示明确上限错误。
- [ ] 移除连接后 Localis 不再显示媒体，并在百度账号授权管理中撤销测试应用。

## 网络矩阵

- [ ] 普通家庭 Wi-Fi。
- [ ] 开启 DNS rebinding protection 的路由器。
- [ ] Guest Wi-Fi/AP isolation：应明确提示不可达，而不是无限加载。
- [ ] VPN/Private Relay/DoH 开关前后。
- [ ] DHCP 地址变化后重新运行 `npm run tls:provision`，新地址仍被同一通配符证书覆盖。

只有三类设备的必测项均通过，才能对外写“Vision Pro / Quest / PICO 真机兼容”；只有对应真实账号部分完成，才能写“真实夸克/百度账号已验收”。
