## Localis 0.4.0

这是一次面向画质、安全回退与可发布性的完整升级。Localis 仍坚持同一个方向：**头显零安装，私人媒体与 AI 计算留在自己的 Windows 电脑上。**

### 这次有什么不同

- **更可信的高画质路径**：新增 HDR10、HLG、10-bit SDR、杜比视界与未知色彩信号分类；在证据充分时允许原片，在不确定或失败时回退到电脑端兼容 HLS。
- **更清楚的播放结果**：播放器会显示实际使用的是原片、兼容流、电脑超分还是 AI 清晰，不把“能够播放”误写成 HDR 保真。
- **AI 清晰完整预处理**：随 Windows 包提供 Real-ESRGAN NCNN Vulkan；整片完成并校验后才开放播放，避免边处理边播放造成的中途失败。
- **Localis 文件夹窗口**：添加媒体时使用网页内的暗色文件夹浏览器，始终位于应用最前层，不再弹出原始且可能藏到桌面的 Windows 窗口。
- **可追溯安装包**：Web、媒体服务、Electron 与诊断文件使用同一个 commit SHA 和 `buildId`。Release 同时提供安装版、便携版、CycloneDX SBOM 与 SHA-256。

### 下载

- `Localis-Setup-0.4.0-x64.exe`：标准安装版，可选择安装目录并创建快捷方式。
- `Localis-Portable-0.4.0-x64.exe`：便携版，不执行安装流程。
- `SHA256SUMS.txt`：安装包与 SBOM 的 SHA-256。
- `Localis-0.4.0-sbom.cdx.json`：CycloneDX 软件物料清单。

Windows 包当前没有商业代码签名，SmartScreen 可能在首次运行时提示未知发布者。请只从本 Release 下载，并核对 `SHA256SUMS.txt`。

### 升级与使用

关闭正在运行的旧版本后安装 0.4.0。默认数据目录中的媒体目录与设置会保留；发布前仍建议自行备份重要配置。局域网普通播放可以使用 HTTP，但 WebXR 需要浏览器认可的 HTTPS 安全上下文。

### 仍在验证

Vision Pro、Quest、PICO 的真机 HDR 观感、90 分钟浸泡测试，以及百度/夸克真实账号闭环尚未完成。本版本提供保守能力判断与安全回退，不宣称已经获得三平台或杜比视界认证。详情见 [测试报告](https://github.com/hanxiaoyu-cmd/localis-xr-media-server/blob/v0.4.0/docs/TEST_REPORT.md) 与 [头显验收清单](https://github.com/hanxiaoyu-cmd/localis-xr-media-server/blob/v0.4.0/docs/HEADSET_ACCEPTANCE.md)。
